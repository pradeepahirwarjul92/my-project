Basic Example

Without RefreshScope

@Service
public class EmployeeService {

    @Value("${app.message}")
    private String message;

}


Property changes in Config Server:
app.message=Hello New Value

Result:

Application restart required.

Using @RefreshScope

@Service
@RefreshScope
public class EmployeeService {

    @Value("${app.message}")
    private String message;

}

After:
POST /actuator/refresh

Bean gets refreshed.

New value available immediately.

Senior-Level Answer to Remember

What is @RefreshScope?

@RefreshScope allows Spring-managed beans to reload configuration properties dynamically without restarting the application.

Internally it uses a proxy. When a refresh event occurs, Spring destroys the existing bean instance and recreates it with updated configuration values.
