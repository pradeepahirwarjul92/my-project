IMPORTANT INTERVIEW COMPLEXITIES
=================================

Linear Search      -> O(n)
Binary Search      -> O(log n)

Bubble Sort        -> O(n²)
Selection Sort     -> O(n²)
Insertion Sort     -> O(n²)

Merge Sort         -> O(n log n)
Quick Sort Avg     -> O(n log n)
Quick Sort Worst   -> O(n²)

Heap Sort          -> O(n log n)

Counting Sort      -> O(n+k)
Radix Sort         -> O(d*(n+k))
Bucket Sort Avg    -> O(n)
