What is Service Discovery?

Service Discovery is a mechanism that allows microservices to dynamically find and communicate 
with each other without hardcoding IP addresses or hostnames.

Service Discovery vs Load Balancing
| Service Discovery | Load Balancing       |
| ----------------- | -------------------- |
| Finds Service     | Selects Instance     |
| Registry Based    | Traffic Distribution |
| Eureka/Consul     | LoadBalancer/NGINX   |



Service Discovery vs API Gateway

| Service Discovery       | API Gateway          |
| ----------------------- | -------------------- |
| Internal Service Lookup | External Entry Point |
| Service-to-Service      | Client-to-Service    |
| Registry                | Routing Layer        |


Common Production Problems

Service Not Found

Check:
		1. Service Registration
		2. Eureka URL
		3. Network Connectivity
		4. Service Name
		5. Registry Status

Stale Instances
	Cause:
		Heartbeat Failure
		Improper Shutdown	
	Solution:
		Lease Expiration
		Health Checks
