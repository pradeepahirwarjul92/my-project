Why BFF?	  

	-	UI-specific API responses
	-	Reduced frontend complexity
	-	Aggregation of multiple microservices
	-	Better security control
	-	Reduced network round trips
	-	Independent evolution of web and mobile APIs
	
Real Production Example
Problem:
Dashboard API was taking 4-5 seconds.

Root Cause:
Frontend called:
1. User Service
2. Order Service
3. Product Service
4. Notification Service

Sequentially.

Solution:
Implemented BFF with parallel WebClient calls.

Before:
4.8 seconds

After:
900 ms

Improvement:
~80% latency reduction.
