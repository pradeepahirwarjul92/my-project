Kafka vs RabbitMQ
| Feature    | Kafka                | RabbitMQ        |
| ---------- | -------------------- | --------------- |
| Use Case   | Event Streaming      | Messaging       |
| Throughput | Very High            | Medium          |
| Ordering   | Per Partition        | Per Queue       |
| Retention  | Days/Months          | Until Consumed  |
| Replay     | Supported            | Limited         |
| Best For   | Microservices Events | Task Processing |

Spring Boot Kafka Example

@KafkaListener(
    topics = "employee-topic",
    groupId = "employee-group"
)
public void consume(String message) {
    System.out.println(message);
}


Spring Boot RabbitMQ Example

@RabbitListener(queues = "employee.queue")
public void consume(String message) {
    System.out.println(message);
}
