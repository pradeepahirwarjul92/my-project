Most Asked Spring Boot Interview Questions

1. What is @SpringBootApplication?

@SpringBootApplication
public class Application {
}


Equivalent to:
@Configuration
@EnableAutoConfiguration
@ComponentScan

Explanation
@Configuration
    -> Configuration Class

@EnableAutoConfiguration
    -> Auto Configuration

@ComponentScan
    -> Scans Components
	
	
	
2. How Auto Configuration Works
Example:

Dependency added:
spring-boot-starter-web


Spring Boot automatically creates:

DispatcherServlet

Tomcat

Jackson

Message Converters

Error Controller

Without manual configuration.

Interview favorite.


3. Spring Boot Startup Flow

main()
   |
SpringApplication.run()
   |
Create ApplicationContext
   |
Load Auto Configurations
   |
Component Scan
   |
Create Beans
   |
Embedded Tomcat Starts
   |
Application Ready


4. Bean Lifecycle
Instantiate Bean
      |
Dependency Injection
      |
@PostConstruct
      |
Bean Ready
      |
Business Use
      |
@PreDestroy
      |
Destroy Bean

Example:
@PostConstruct
public void init() {
    System.out.println("Initialized");
}

@PreDestroy
public void cleanup() {
    System.out.println("Destroyed");
}



5. @Component vs @Bean

@Component

@Component
public class EmployeeService {
}

Auto-detected by component scanning.


@Bean

@Configuration
public class AppConfig {

    @Bean
    public ObjectMapper objectMapper() {
        return new ObjectMapper();
    }
}

Used when creating third-party objects.


6. @Value vs @ConfigurationProperties
@Value
@Value("${server.port}")
private int port;

Single property.

@ConfigurationProperties
@ConfigurationProperties(prefix="db")
public class DbProperties {

    private String url;
    private String username;
}

Preferred for multiple properties.
