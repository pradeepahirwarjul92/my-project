=================================================
IMPORTANT DIFFERENCES
=================================================

Date vs LocalDate

Date:
- Mutable
- Old API
- Not Thread Safe

LocalDate:
- Immutable
- Thread Safe
- Java 8 API

-------------------------------------------------

Period vs Duration

Period:
Years, Months, Days

Duration:
Hours, Minutes, Seconds

-------------------------------------------------

Instant vs LocalDateTime

Instant:
UTC Timestamp

LocalDateTime:
Date + Time without timezone

PRODUCTION SCENARIOS
=================================================

Scenario 1:
Different timezone on servers.

Fix:

Store everything in UTC

Instant.now()

-------------------------------------------------

Scenario 2:
API returns wrong date.

Reason:
Server timezone mismatch.

Fix:

Use ZonedDateTime

-------------------------------------------------

Scenario 3:
Scheduler runs at wrong time.

Reason:
Timezone not specified.

Fix:

@Scheduled(cron="0 0 10 * * *",
zone="Asia/Kolkata")

-------------------------------------------------

Scenario 4:
Date Parsing Error

Exception:

DateTimeParseException

Fix:

Correct formatter pattern.
