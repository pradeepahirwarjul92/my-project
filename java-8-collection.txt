HASHMAP INTERNAL WORKING
=================================================

put(key,value)

Step 1:
Calculate hashCode()

Step 2:
Find bucket index

index = hash % capacity

Step 3:
Store Entry

If collision:
- Linked List (Java 7)
- Linked List + Red Black Tree (Java 8)

=================================================

 Node
 |
 Node
 |
 Node

O(n)

After Java 8:

REAL PRODUCTION SCENARIOS
=================================================

Scenario 1:
HashMap Slow

Reason:
Poor hashCode()

Result:
All entries in one bucket.

Complexity:

O(n)

Fix:
Proper hashCode()

-------------------------------------------------

Scenario 2:
ConcurrentModificationException

Reason:

Modifying collection during iteration.

Fix:

Iterator.remove()

or

Concurrent Collections

-------------------------------------------------

Scenario 3:
Memory Leak

Reason:

Static Map continuously growing.

Fix:
Eviction Policy
Cache Cleanup

-------------------------------------------------

Scenario 4:
Duplicate Entries in HashSet

Reason:

equals/hashCode not overridden.

Fix:

Override both methods.
