Blue-Green Deployment Architecture

                    Users
                      |
                      v
               Load Balancer
                      |
          -------------------------
          |                       |
          v                       v
   BLUE Environment       GREEN Environment
 (Current Production)      (New Release)

Before Switch:
Traffic -> BLUE

After Validation:
Traffic -> GREEN

If Failure:
Rollback -> BLUE



Q: What is Blue-Green Deployment?

Answer:
Blue-Green Deployment is a release strategy where two identical production environments exist:

Blue = Current live production version
Green = New application version

The new version is deployed to Green, tested, and then traffic is switched from Blue to Green through 
a load balancer, API Gateway, or Kubernetes Service. If issues occur, rollback is achieved instantly by redirecting traffic back to Blue.

Benefits
Near-zero downtime
Fast rollback
Safer releases
Better production testing
Reduced deployment risk
