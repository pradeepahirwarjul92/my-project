COLLECTION TIME COMPLEXITIES

ArrayList
get()       -> O(1)
add()       -> O(1)
remove()    -> O(n)
search()    -> O(n)

LinkedList
get()       -> O(n)
add()       -> O(1)
remove()    -> O(1)

HashMap
put()       -> O(1)
get()       -> O(1)
remove()    -> O(1)

TreeMap
put()       -> O(log n)
get()       -> O(log n)
remove()    -> O(log n)

HashSet
add()       -> O(1)
remove()    -> O(1)
contains()  -> O(1)

TreeSet
add()       -> O(log n)
remove()    -> O(log n)
contains()  -> O(log n)
